# Agent-First Design System (Professional Standard)

## Core Logic

- **Tactical Aesthetic**: Use dark modes, glassmorphism, and neon-functional borders.
- **Data Density**: Prioritize information density over "airy" whitespace.
- **Micro-Animations**: Use pulse states and order-flow-dots to show the system is alive.

## Instructions

1.  **Color Context**:
    - **Blue (CB-Blue)**: Intake / Phase 1.
    - **Indigo (CB-Indigo)**: Strategy / Phase 2.
    - **Green (CB-Green)**: Execution / Phase 3.
2.  **Typography**: Use monospaced fonts for data and terminal-style headers.
3.  **Interactive Diagrams**: Always quote Mermaid labels and use professional stubs for logic transitions.

## Mandatory Self-Improvement Audit

After EVERY skill use, perform this audit:

1. **Instruction Clarity**: Did any step produce an unexpected or ambiguous result?
2. **Trigger Coverage**: Is the description "pushy" enough?
3. **Gap Analysis**: If a gap is found, fix it immediately. Otherwise, state: `skill(design-system): no gaps identified`.
