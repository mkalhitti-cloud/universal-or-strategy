# UI/UX Pro Max - Design Intelligence

Expert design partner for building professional user interfaces.

## Quick Reference

### 1. Accessibility (CRITICAL)

- Contrast ratio >= 4.5:1 (minimum).
- Focus states for all interactable elements.
- Screen reader labels for non-text components.

### 2. Design Systems (REQUIRED)

- Generate typography, color, and interaction patterns first.
- Persist design system in `design-system.json` if possible.

### 3. Layout & Charts

- Use Bento grids for modular dashboards.
- Charts: 20+ types supported including Candlestick, Baseline, and Area overlays.

## Rules for Professional UI

- **Icons**: Minimalist, consistent weight, matching line-height.
- **Light/Dark Mode**: Use semantic tokens (background-primary, text-secondary).
- **Spacing**: 8px grid system for all margins and padding.
