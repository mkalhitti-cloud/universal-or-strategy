# Archive Processing Pipeline

## Architecture — 3-Tier Bob Agent System

```
TIER 1: Media Architect (You / account_01)
    Bob — designs, assigns, monitors, never touches individual clips
    Script: 01_director.py
    Runs:   run_archive_pipeline.ps1

    │
    ├── TIER 2: Pipeline Orchestrators (accounts 02-20)
    │       One account per batch of ~12 sessions
    │       Manages all 5 stages for their batch
    │       Script: 02_pipeline_orchestrator.py
    │
    │       │
    │       └── TIER 3: Stage Workers (accounts 21-90)
    │               Accounts 21-30:  DOWNLOAD   (yt-dlp + local copy)
    │               Accounts 31-45:  TRANSCRIBE (Whisper)
    │               Accounts 46-60:  ANALYZE    (Claude + keyword fallback)
    │               Accounts 61-75:  EXTRACT    (FFmpeg)
    │               Accounts 76-90:  METADATA   (Claude + template fallback)
```

## Quick Start (Media Architect)

### Step 1 — Build manifest
```powershell
.\scripts\archive_agent\run_archive_pipeline.ps1 -Step build
```

### Step 2 — Assign batches to Tier 2
```powershell
.\scripts\archive_agent\run_archive_pipeline.ps1 -Step assign
```

### Step 3 — Check status anytime
```powershell
.\scripts\archive_agent\run_archive_pipeline.ps1 -Step status
```

### Step 4 — Test on one session (with video file ready)
```powershell
.\scripts\archive_agent\run_archive_pipeline.ps1 -Step test -Session session_001
```

### Step 5 — Full pipeline for one session (downloads too)
```powershell
.\scripts\archive_agent\run_archive_pipeline.ps1 -Step full -Session session_001
```

## Worker Bootstrap (Tier 2 and Tier 3)

Each account reads its assignment file and runs one command:

**Tier 2 Orchestrator (account_02):**
```powershell
# Read: worker_assignments/account_02.md
python scripts/archive_agent/02_pipeline_orchestrator.py --account account_02 --assign-tier3
```

**Tier 3 Worker (account_21 — download):**
```powershell
# Read: worker_assignments/account_21_download_session_001.md
python scripts/archive_agent/03_download_worker.py --session session_001
```

## Pipeline Stages

| Stage | Script | Input | Output | Worker Accounts |
|-------|--------|-------|--------|-----------------|
| Download | 03_download_worker.py | URL or local path | archive/raw/{id}.mp4 | 21-30 |
| Transcribe | 04_transcribe_worker.py | .mp4 | archive/transcripts/{id}.json | 31-45 |
| Analyze | 05_analyze_worker.py | transcript.json | {id}_clips.json | 46-60 |
| Extract | 06_extract_worker.py | .mp4 + clips.json | archive/clips/\*/ | 61-75 |
| Metadata | 07_metadata_worker.py | clips.json | archive/metadata/{id}.json | 76-90 |

## Output Structure

```
archive/
  archive_manifest.json     ← Master pipeline state
  raw/                      ← Downloaded source videos
  transcripts/
    {session_id}.json       ← Whisper transcript with word timestamps
    {session_id}_clips.json ← Clip boundaries identified by analyze worker
  clips/
    shorts/                 ← <60s clips (vertical 9:16)
    medium/                 ← 8-15 min clips
    full/                   ← Full sessions
  metadata/
    {session_id}_metadata.json ← YouTube titles, descriptions, tags, thumbnails
  thumbnails/               ← Generated by Higgsfield MCP (separate pipeline)

worker_assignments/
  account_02.md             ← Tier 2 orchestrator bootstrap
  account_XX_download_session_YYY.md  ← Tier 3 worker bootstrap
```

## Teachable Download Setup

To download from Teachable, export browser cookies:

1. Install browser extension: "Get cookies.txt LOCALLY"
2. Log into your Teachable school
3. Export cookies for teachable.com
4. Save as: `.env.teachable_cookies` (gitignored)

Then pass URL to download worker:
```powershell
python scripts/archive_agent/03_download_worker.py --session session_001 --url "https://..."
```

## Claude API Setup (Optional — enhances analyze + metadata)

Set in your environment:
```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-..."
```

Without it, the pipeline uses keyword-based analysis (still works, less precise).

## Git Coordination

All workers commit their outputs. Media Architect monitors via:
```powershell
git log --oneline -20
.\scripts\archive_agent\run_archive_pipeline.ps1 -Step status
```
