# Technical Debt Brain Directory

This directory contains all structured debt tracking for the V12 project.

## Files

### `okf-violation-scan.md` / `okf-violation-scan.json`
Generated by `scripts/scan_okf_violations.py`. Scans all `src/*.cs` files for
pre-existing OKF rule violations that `complexity_audit.py` does NOT detect
(it only finds CYC > 8). This covers:

- P0: `lock()` calls (Rule 1 -- hard ban)
- P1: `DateTime.Now` in production logic (Rule 3 -- FSM Determinism)
- P2: `Account.All` / `.Orders` / `.Positions` without `.ToArray()` snapshot (Rule 5)
- P3: `.Instrument.FullName` / `.Name` without null guard (Rule 5)
- P4: SA1503 braces, SA1204 ordering, naming violations (Rule 12)

Run before every wave Phase 0 to get the current debt surface.

## Debt Registers

### `../wave7-pr-repairs/deferred-debt-register.md`
Append-only register of out-of-scope violations discovered during Phase 7 PR lane
reviews. Written by `wave-orch-phase7-lane` instances (STEP 5a). Covers Wave 7.

Future waves will add their own registers here:
- `wave8-pr-repairs/deferred-debt-register.md` (Wave 8)
- etc.

## Suppressed Repairs (NEEDS_DIRECTOR)

Findings that lanes classified as `NEEDS_DIRECTOR` are tracked in each PR's
`repair-log.md` and aggregated in `needs-director-register.md`.

### `needs-director-register.md`
Architectural decisions that require Director judgment before a lane can fix them.
These are NOT bugs a lane can auto-apply -- they require design decisions.
